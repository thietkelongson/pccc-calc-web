# PCCC Calc — Web tính toán PCCC

Bộ công cụ web cho thiết kế Phòng cháy chữa cháy (PCCC) theo tiêu chuẩn Việt Nam: TCVN 7336, QCVN 10:2025/BCA, QCVN 06:2022 và các tiêu chuẩn liên quan.

🌐 **Demo**: https://thietkelongson.github.io/pccc-calc-web/

## Tính năng

**Tra cứu**
- 📖 [Tra cứu QC10](qc10-lookup.html) — yêu cầu trang bị PCCC theo QCVN 10:2025/BCA
- 🚰 [Tra cứu TCVN 7336](tcvn7336-lookup.html) — cường độ phun, lưu lượng, diện tích, thời gian phun

**Tính toán**
- 💧 [Sprinkler Isometric](sprinkler-network.html) — vẽ sơ đồ 3D + tính thủy lực Hazen-Williams

## Trạng thái

Prototype giai đoạn 1 — frontend tĩnh, chưa có backend. Một số nút (đăng nhập, thanh toán, lưu dự án, export PDF/Excel/DXF) là **mock UI** để demo flow.
